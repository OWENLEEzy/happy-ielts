数据库表一览

路径 A — 英语精读飞轮
articles— 每日文章 + highlight_indices
writing_tasks— 写作任务 + mode + min_words
writing_submissions— 用户写作 + feedback
vocab_items— 生词 + FSRS 状态 + source
observations.jsonl— 每课观察 (7天)
student_model.json— 学生画像 + level + error_patterns
路径 B — 通用知识学习
learning_projects— 项目 + goal_profile + LearningMap
notebooks— NotebookLM notebook_id 映射
general_lessons— study_guide + quiz_json + flashcards
project_sessions— 课次记录 + quiz_score
general_student_model— dimensions + fsrs_due + goal_progress
db.sqlite3 — 应用数据（articles, writing_tasks, submissions, vocab_items, learning_projects, lessons, sessions）   |   checkpoints.sqlite3 — LangGraph checkpoint（tutor graph + onboarding + general lesson 的 thread 状态）
